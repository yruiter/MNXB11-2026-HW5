1. Describe briefly what a static/dynamic library is and some reasons to use one over the other

The code of a static library is copied directly into the executable at comiple time while, the code of a dynamic library is external 
and is loaded when the proramm is compiling. Preference over one or the othe can depend on runtime dependencies or smaller executable size.
